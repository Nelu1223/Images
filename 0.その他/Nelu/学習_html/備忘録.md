## 背景実装_20251213 background  
cssと併用することで、サイトの背景を実装することが可能

```
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title>備忘録</title>

    <style>
      #wrapper .wallpaper {
        left: 0;
        right: 0;
        top: 0;
        bottom: 0;
        position: fixed;
        width: 100%;
        height: 100%;
        background-size: cover;
        background-position-x: 50%;
        background-position-y: 0%;
        opacity: 1;
      }
    </style>
  </head>
  <body class="sample">


    <div id="wrapper">
      <div class="back-image">
        <div class="wallpaper" style="background-image:url('backimage2.jpeg')">
        </div>
      </div>
    </div>
    
  </body>
</html>
```

このコードにおいて、<style>の部分で背景のスタイル情報を書き込んでいる。
#[親class/id名] .[class名]であらわすことで、[親class/id名]の中の[class名]に情報が渡される。
直接<div style="">で情報を指定することも可能。

### 〇情報一覧
- left,right,top,bottom: それぞれ左,右,上,下の描画境界位置を指定
- position: 一番目の4つのプロパティと合わせて使用し、要素の配置方法を指定（flexd: ビューポートを基準に画面に固定）
- width,height: それぞれ画像の横幅,立幅を指定（px,%,auto のいずれかで指定）
- background-image:url('画像のパス'): 表示する画像の指定
- background-size: 画像のサイズを指定（auto: もとのまま cover: ウィンドウサイズに合わせる contain: よくわからん px,%: 直接値指定、背景なら基本coverでOK）
- bacnground-positon-x,y: それぞれ画像の表示されるx,y座標を指定（px,%,left/top,right/bottom,center）
- opacity: 不透明度の指定（0:完全透明 1: 完全不透明 rgba(r,g,b,a): rgb指定とaで不透明度指定）

以下のようにして一つ親のクラスに描画境界位置を指定しておけば、その中のクラスにはすべてその情報が適応される。

```
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title>Cafe-Steria Home</title>

    <style>
      #wrapper .back-image {
        left: 0;
        right: 0;
        top: 0;
        bottom: 0;
        position: fixed;
      }
      #wrapper .wallpaper {
        width: 100%;
        height: 100%;
        background-size: cover;
        background-position-x: 50%;
        background-position-y: 0%;
        opacity: 1;
      }
    </style>
  </head>
  <body class="cafe-steria-home">


    <div id="wrapper">
      <div class="back-image">　<!-- この中のクラスにはすべて"back-image"の描画境界位置が指定される-->
        <div class="wallpaper" style="background-image:url('backimage2.jpeg')">
        </div>
      </div>
    </div>
    
  </body>
</html>
```
