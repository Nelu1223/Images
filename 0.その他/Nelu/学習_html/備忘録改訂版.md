## HTML  
HTMLはウェブサイトを作成する際に用いられる言語であり、これを知らずにウェブサイトを作成することはできません。  
ここでまとめられている情報は基本的に以下の参考文献をもとに作成しています、詳しく知りたいかたはそちらをぜひご覧ください。  

**・[初心者向けHTML入門：書き方の基本とタグの使い方](https://saruwakakun.com/html-css/basic/html)**  


### 基礎   
HTMLでウェブサイトを作るときは以下の基本形を用います。  

<Sample.html>
```
<!DOCTYPE html>
<html>
<head>
  <title>ウェブサイトのタイトル</title>
  <meta charset="UTF-8" \>
</head>
<body>
  <h1>見出し-1段階</h1>
  <h2>見出し-2段階</h2>
  <p>内容</p>
  <a href="https://x.com/elega_sophi">X (えれが🐾🎨)</a>
</body>
</html>
```
必ず`<!DOCTYPE html>`を初めにかき、`<html> </html>`で囲んでください、理由や意味は割愛します、気になったら調べてみてください。  
大きく分けて<head></head>で挟まれているページに表示されない裏側の情報である"文書メタデータ"\*1 と、<body></body>で挟まれているページに表示される表側の情報である"文書本体要素"\*2 に分けられています。  
上記のコードを.htmlとして保存し、ブラウザで開くもしくはブラウザウィンドウにドラッグすることで内容を確認することができます。  


### タグ
HTMLのプルグラムは`<xxx> </xxx>`という表記が使われます。    
これは"**タグ**"と呼ばれ、これに情報を挟むのがHTMLの基本形となります。  
先ほどの`<head> </head>`や`<body> </body>`もタグであり、ほかにもサンプルプログラムで使用されている`<title> </title>`は、ウェブページのタブに表示されるタイトルを指定するタグであり、`<p> </p>`はウェブページに表示される本文を指定するタグになっています。  

タグの頭を"開始タグ"といいますが、サンプルプログラムの`<a href~`の行のように開始タグ内に情報を入れることがあり、これを"**属性**"と呼びます。  
属性は`xxx="yyy"`で指定され、サンプルプログラムでの`href="https:..."`の部分がこれに当たります、`<a> </a>`はページ移動用のリンクを作成するためのアンカー要素であり、この属性がジャンプ先のアドレスを指定しています。  


### id/class  
`id`や`class`は開始タグ内で指定できる属性の1つで、タグに管理名を指定します。  
管理名をつけると、その管理名をつけられたすべてのタグのスタイル情報などをcssで一括で指定したりすることが可能になり、非常に便利であるため指定することをおすすめします。  
これはどのタグタイプでも指定することができ、**基本的にid名およびclass名は英数字と"-"を用います (先頭に数字は×)。**  
`id`は**同じ名前を2度は使用できない**のに対し、`class`は**いくつでも同じ名前を使用できます**、理由は`id`はページ内の特定の1か所を特定するために使用するのに対し、`class`はタグのスタイルや性質を指定するためです。  
たとえるなら、`id`は学籍番号や社員番号など個人を特定するためのものなのに対し、`class`は学生や駅員さんなど、特定の集団に限定し服装やルールを定めるために使用されるという感じです。  
id/classを用いた情報の指定はcss項目の[クラス](https://github.com/Nelu1223/Images/blob/main/0.%E3%81%9D%E3%81%AE%E4%BB%96/Nelu/%E5%AD%A6%E7%BF%92_html/%E5%82%99%E5%BF%98%E9%8C%B2%E6%94%B9%E8%A8%82%E7%89%88.md#%E3%82%AF%E3%83%A9%E3%82%B9)を参照してください。  


### div/span  
`<div> </div>`や`<span> </span>`はコードのまとまりを作ることができるタグです、javaでのメソッドに近い気がします。  
もともと1つだったものをただまとめても表示される内容に変化はありませんが、このまとまりに先ほどの`id`/`class`属性を指定してあげればそれぞれ別のデザインを変更することができます。  
`<div>`と`<span>`の違いは、`<div>`は**前後が改行されてしまう**"インライン要素"なのに対し、`<span>`は**改行が入らず並べて表示される**"ブロック要素"であることです。  
この使用を活用することで、例えば文章中の一部分の文字の色を変えたりすることが可能です。

## CSS  
cssを活用することで表示内容などに様々なスタイル情報などを渡すことができ、よりおしゃれなページ作りが可能になります。  
cssは  
1. .cssファイルを作成し書き込む  
2. `<head> </head>`内に`<style> </style>`タグを作成しその中に書き込む  
3. タグの`style`属性に書き込む  

の3つの方法で指定可能です。  
2,3はそのままなので1のファイルを作成して書き込んだ内容を実際にHTMLに読み込む方法を示します。 


### .cssファイルを読み込む  
.cssファイルを読み込むには`<head> </head>`内で`<link>`タグを使用して読み込ませるファイルを指定します。  
```
<head>
  <link rel="stylesheet" href="css/sample.css">
</head>
```
`rel`属性は指定したファイルとの関係を示しているため、.cssファイルを読み込む場合`styleshee`を指定します。
`href`属性には読み込ませたい.cssファイルのパスを指定してください、今回はこのサンプルプログラムファイルと同じ場所に"css"という名前のフォルダがあり、その中にある"sample.css"を指定しています。  


### 書き込み形式  
cssによるスタイルの指定の書き方は`xxx {}`という形が基本です。  
`xxx`は適応先のタグ/id/classを示し、{}内に情報を書き込みます。  
#### 適応先の指定  
適応先である`xxx`はタグ/id/classそれぞれで描き方が異なります。
**タグ**を指定する場合、何も書かずそのまま`タグ名 {}`と書きます。
```
p {
  color: red;
}
```
上記のように書くと、読み込ませたHTMLファイル内の`<p>`タグすべてに居間指定したスタイル情報が適応されます、このプログラムをそのまま書くと本文がすべて真っ赤になります。  
**id**を指定する場合はid名の前に**\#**を付けます。  
```
#sample-id {
  color: red;
}
```
これによって指定したid内のタグすべてにこのスタイル情報が適応されます。  
**class**を指定する場合はclass名の前に**.**を付けます。  
```
.sample-class {
  color: red;
}
```
これによって指定したclassの属性を持つタグすべてにこのスタイル情報が適応されます。  
複数適応先を指定したい場合は**,**で区切ります。  
また"xxのid内のyyのclass"と絞ることもでき、半角スペースで区切って並べることで可能です。  
#### スタイル情報の指定  
スタイル情報は{}内で指定します。  
基本形は`xxx: yyy;`と書きます、`xxx`はプロパティでなんの情報を指定するかを決定し、`yyy`は値で情報の具体的な内容を決定します。  
最後に**;**は絶対忘れてはいけません、javaを経験している方なら気にする必要はないですが、いろいろ経験している方は忘れないようにしましょう。  
ひとつしかないならなくてもいいらしいですが、習慣にした方が楽なので普段からつけることをおすすめします。  

<Sample.html>  
```
<!DOCTYPE html>
<html>
<head>
  <title>ウェブサイトのタイトル</title>
  <meta charset="UTF-8" \>
  <link rel="stylesheet" href="css/sample.css">
</head>
<body>
  <h1>見出し-1段階</h1>
  <h2>見出し-2段階</h2>
  <p>内容</p>
  <img src="icon.png" alt="アイコンの写真" class="sample-img">
  <p></p>
  <a href="https://x.com/elega_sophi">X (えれが🐾🎨)</a>
</body>
</html>
```
<css/sample.css>
```
.sample-img {
  width: 300px;
  border-radius: 10px;
}
```

## java script
java scriptを活用することで動きのあるよりハイレベルなページを作成することができます。  
jsは  
1. .jsファイルを作成し書き込む  
2. `<head> </head>`内に`<script> </script>`タグを作成しその中に書き込む  

の2つの方法で指定可能です。  
2はそのままなので1のファイルを作成して書き込んだ内容を実際にHTMLに読み込む方法を示します。 

### .jsの読み込み
.cssの時と似たような感じで読み込むことができます、以下のようにhtmlファイル内に書き込むだけです。　　
```
<body>
  <script src="java-script/sample.js"></script>
</body>
```
ただし.cssと異なり、**必ず`<body> </body>`タグ内の一番最後に書き込む**必要があります。  
特に一番最後というのが重要で、間違えたところに置くと一生機能してくれないので注意が必要です。

## モーダル  
ページの最前面に新たな画面を描画することができる"モーダル"というスタイルがあります。  
例えば、アイコンをクリックするとそれに対応する画像などをページに大きく表示したい時などに使用可能です。  
ここでは例としてイラストの作品集の作成方法を記します。  
### アイコン画像を表示する  
`<img>`タグを用いて、モーダルを表示するトリガーとなるアイコンを作成します。  
詳しいことはタグ一覧の"[`<img>`タグ](https://github.com/Nelu1223/Images/blob/main/0.%E3%81%9D%E3%81%AE%E4%BB%96/Nelu/%E5%AD%A6%E7%BF%92_html/%E3%82%BF%E3%82%B0%E4%B8%80%E8%A6%A7.md#img)"をご参照ください。  
以下のように`src`属性にアイコンの画像を、`data-full`属性に表示したい全体画像を設定してください。  
```
<div id="gallery">
  <img src="img1_icon.png" data-full="img1_full.png" class="gallery-img" alt="作品1">
  <img src="img2_icon.png" data-full="img2_full.png" class="gallery-img" alt="作品2">
</div>
```
### モーダル(最前面に表示する内容)を作成
モーダルの基本構造は半透明のグレー背景、内容、閉じるためのボタンの3つで構成されています。  
こだわりがなければ以下の基礎構造でモーダルを作成します。  
```
<div id="layer js-modal"> <!--背景-->
  <div id="modal"> <!--コンテンツの基本設定-->
      <div id="modal__contents">　<!--コンテンツ-->
        <span id="modal-img-wrap"></span>
          <img id="modal-img" class="modal-content" src="" alt="拡大画像">　<!--画像-->
        </span>
      </div>
      <!-- ×ボタン追記 -->
      <div id="modal__button-wrap">
        <button class="close-button js-close-button">
          <span></span>
          <span></span>
        </button>
      </div>
    </div>
  </div>
</div>
```
<.css>  
```
/* グレー背景 */
#layer {
  background: rgba(255, 255, 255, .2); /* 背景を薄くする */
  width: 100%;
  height: 100%;
  position: fixed; /* 画面に固定するために指定 */
  top: 0;
  left: 0;
}

/* モーダルコンテンツ */
.modal {
  position: relative;
  margin-right: auto;
  margin-left: auto;
  width: 80%;
  min-width: 440px;
}

/* クローズボタン基礎 */
#modal__button-wrap {
  position: absolute;
  right: 20px;
  top: 5%;
  display: inline-flex;
}

/* クローズボタン下 */
.close-button {
  position: relative;
  width: 50px;
  height: 50px;
  background: rgba(0,0,0,0);
  border-radius: 50%;
  padding: 0;
  border: transparent;
  cursor: pointer;
}

/* クローズボタン×印 */
.close-button span {
  width: 25px;
  height: 2px;
  background: black;
  display: inline-block;
  position: absolute;
  left: calc(50% - 12px);
  top: 50%;
  border-radius: 20px;
}

/* クローズボタンを隠したり表示したりする */
.close-button span:nth-child(1) {
  transform: rotate(45deg) translate(-1px, -1px);
}

.close-button span:nth-child(2) {
  transform: rotate(-45deg) translate(1px, -1px);
}
```
`<img id="modal-img" class="modal-content" src="" alt="拡大画像">`には後ほどjava scriptを使用して全体画像を代入するため`src`は記入しません。  
また、後ほどjava scriptによってモーダルの表示非表示を切り替えるため、`<div id="layer js-modal">`の`js-modal`を記入しています。  
ボタンのあれこれは割愛、こちらの[サイト](https://zero-plus.io/media/javascript-modal/)を参考にさせていただきました。  
実行して半透明の背景が最前面に映されたらOKです。  
### 初期はモーダルを非表示にする
モーダルはアイコンをクリックにしたとき表示するようにしたいため、初期は非表示にしておく必要があります。  
先ほどのサンプルプログラムの.cssファイルの一部分を以下のように変更します。  
<.css>
```
/* グレー背景 */
#layer {
  background: rgba(255, 255, 255, .2); /* 背景を薄くする */
  width: 100%;
  height: 100%;
  position: fixed; /* 画面に固定するために指定 */
  top: 0;
  left: 0;

  /* 追記 */
  z-index: -1; 
  opacity: 0;
  visibility: hidden;
}

/* モーダルコンテンツ */
.modal {
  position: relative;
  margin-right: auto;
  margin-left: auto;
  width: 80%;
  min-width: 440px;

  /* 追記 */
  opacity: 0;
  visibility: hidden;
}

/* 追記 */
.layer.is-open {
  z-index: 999;
  opacity: 1;
  visibility: visible;
}

.layer.is-open .modal{
  opacity: 1;
  visibility: visible;
}
```
簡単に追記内容を説明すると、`z-index: -1;`でモーダルの内容をすべて最背面に移動、`.layer.is-open`と`.layer.is-open .modal`でモーダルを最前面に戻すトリガーを作成しました、このトリガーは後ほど使用します。  
これを追記後もう一度実行し、先ほどの半透明な背景やバツ印が消えていえばOKです。  
### 画像をクリックしてモーダルを表示する
最後にモーダルを表示させます、今回は`is-open`クラスを付与することで最前面に来るようひとつ前でトリガーを作成したため、ここではjava scriptでクラスの付与を行います。  
以下のjava scriptプログラムを.jsファイルに書き込み保存、`<script src=""></script>`を`<body> </body>`の最後に書き込みhtmlファイルに読み込ませることで実装できます。  
<.js>
```
const galleryItems = document.querySelectorAll('.gallery-img');
const modalImg = document.getElementById('modal-img');

const modal = document.querySelector('.js-modal'); // layer要素に付与したjs-modalクラスを取得し変数に格納
const modalClose = document.querySelector('.js-close-button'); // クローズボタン要素に付与したjs-modal-buttonクラスを取得し、変数に格納

const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

//アイコンをクリックしたときのイベント登録
galleryItems.forEach(item => {
  item.addEventListener('click', async () => {
    console.log('clicked!');
        //クリックされた画像に対応する全体画像を取得
        const fullImgUrl = item.getAttribute('data-full') || item.src;
        //モーダルの画像タグに全体画像を設定
        modalImg.src = fullImgUrl;
        
        //モーダルを表示状態にする
        await sleep(500);
        modal.classList.add('is-open');
  });
});

//クローズボタンをクリックしたときのイベント登録
modalClose.addEventListener('click', () => { // xボタンをクリックしたときのイベントを登録
  modal.classList.remove('is-open'); 
  
  modalImg.src = null;
});
```
簡単に言えば、1個目はアイコンをクリックしたとき描画する内容を設定して0.5s後にクラスを与えてモーダルを表示、2個目はクローズボタンをクリックしたときクラスを取り除きモーダルを非表示、その後内容をクリアしています。  
後はモーダルの内容をお好きなものに変更していただければモーダル実装が完了です。

## カーソルを合わせることでアクション
`:hover`をcssで使用することでカーソルを重ねたときの変化をjava scriptなしで実装可能です。  
今回は例として画像にカーソルを合わせたときカーソルが指マークになり、画像が拡大するようなスタイルを作ります。  
まず画像を以下のようにして実装します。  
<.html>
```
<span class="img-wrap">
  <img src="img.png" class="img-con" alt="画像">
</span>
```
`img-wrap`は画像の土台です、これにカーソルに合わせたときの信号を受け取るように.cssを以下のように作成します。  
<.css>
```
.icon-wrap {
    width: 200px;
    height: 200px;
    border-radius: 10px;

    /* 土台からはみ出た画像を隠す */
    overflow: hidden;

    /* カーソルを重ねたときカーソルを指の形に */
    cursor: pointer;

    /* 画像を横並びにする */
    display: inline-flex;
}

.icon-wrap .gallery-img{
    width: 100%;
    height: 100%;

    /* 土台に合わせる */
    object-fit: cover;

    /* 変形を0.3sで行う */
    transition: transform 0.3s ease;
}

/* :hoverでカーソルが重なったときのアニメーションを実装 */
.icon-wrap:hover .gallery-img {
    /* 1.1倍に拡大 */
    transform: scale(1.1); 
}
```
これでカーソルを合わせると変形するようになりました。
