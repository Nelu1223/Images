## HTML基礎  
HTMLでウェブサイトを作るときは以下の基本形を用います。  
<Sample.html>
'''
<!DOCTYPE html>
<html>
<head>
  <title>ウェブサイトのタイトル</title>
  <meta charset="UTF-8">
</head>
<body>
  <h1>見出し-1段階</h1>
  <h2>見出し-2段階</h2>
  <p>内容</p>
</body>
</html>
'''
