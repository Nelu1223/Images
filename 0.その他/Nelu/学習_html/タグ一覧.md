## HTML \<head>
### \<link>  
ページと外部リソースとの関係を指定するタグ、アンカー要素である`<a>`との違いはアンカー要素はページを訪れた人に対して特定のリンクとのつながりを示すものであるのに対し、`<link>`はブラウザ側に指定したリンク先のファイルなどとの関係を示している。
##### 属性  
`rel`  
指定したリンクとページとの関係を指定する属性、`"stylesheet"`は指定した.cssファイルを読みこませ、`"canonical"`は指定したリンクが正規であることを示す。
`href`  
関係のあるリンクを指定する属性。
```
<link rel="stylesheet" href="https://xxxx.css" >
```

---
### \<meta>  
メタデータを指定するタグ、このタグは終了タグを表記せず、`<meta 属性 \>`で表す。  
##### 属性  
`charset`  
文字エンコーディングを宣言する属性、何もないなら`charset="UTF-8"`で大丈夫。  
`http-equiv`  
ブラウザへの指示を指定する属性。  
例えばリダイレクトを`http-equiv="refresh"`で指定でき、`content`属性でリダイレクト時間とリダイレクト先のリンクを指定可能。  
```
<meta http-equiv="refresh" content="3;url=https://www.mozilla.org" />`
```
`content`  
`http-equiv`属性または`name`属性に関連する値を指定可能、`name`の場合その値をしていする。  

---
### \<title>  
ウェブページのタグに表示されるページのタイトルを設定可能。  
```
<title>備忘録</title>
```

## HTML \<body>
### \<a>
アンカー要素を指定するタグ、主に特定のアドレスのページにジャンプするハイパーリンクを作成するときに用いる。  
##### 属性  
`href`  
ジャンプ先のアドレスを指定できる。  
```
<a href="https://x.com/elega_sophi">X (えれが🐾🎨)</a>
```

---
### \<br>  
`<p>`タグ内などに単体で置くことで改行が可能、`<p>`タグを並べるより行間が短くなる。  
```
<p>ここで▷<br>◁改行</p>
```
　↓  
ここで▷  
◁改行  

---
### \<hx>  
見出しを指定するタグ、`x`には1～6の数字が入り、数字が小さいほど大きい見出し文字になる。  
```
<h1>見出し</h1>
```

### \<img>    
表示する画像の情報を指定できるタグ、終了タグを使用せず、`<img 属性 \>`で表す。  
表示することができるファイル形式が決まっているので表示されない場合、一度ファイル形式を確認するといいかも。  
同じ情報を指定した画像をたくさん使いたい場合は`class`属性を指定し、cssを活用して一度に情報を指定することをおすすめ、詳しくは[備忘録](https://github.com/Nelu1223/Images/blob/main/0.%E3%81%9D%E3%81%AE%E4%BB%96/Nelu/%E5%AD%A6%E7%BF%92_html/%E5%82%99%E5%BF%98%E9%8C%B2%E6%94%B9%E8%A8%82%E7%89%88.md#%E3%82%AF%E3%83%A9%E3%82%B9)を参照。  
##### スタイル情報  
`width`/`height`  
画像の幅/高さを指定可能、`300px`や`300`だとピクセルで、`50%`だとパーセントで指定できる。  
`border-radius`
画像の角を丸めることができる、ピクセル指定で丸める半径を決定できる。
`opacity`  
画像の不透明度を指定可能、0が透明で1が不透明。  
`filter`  
画像に特殊効果を与えることが可能。  
・`blur()`: ぼかし  
・`grayscale()`: モノクロ化  
・`brightness()`: 明るさ指定  
・`contrast()`: コントラスト指定  
##### 属性  
`class`  
情報をcssから受け取る場合のクラス名を指定できる。  
`scr`/`scrset`  
表示する画像のパスやURLを指定できる、`scr`は1つの特定のパス、`scrset`は複数のパスを指定でき訪れた相手側の描画幅に応じて画像を変更できる。  
どちらか一方を必ず指定する必要があり、`scrset`の場合は幅記述子を提供する必要がある。  
ちょっとよくわからないので、とりあえず`scr`でいいと思う。  
`alt`  
代替情報のテキストを指定できる、何かのエラーで画像が読み込まれなかった場合に表示される。  
`data-full`  
`scr`で指定した画像より高画質な画像を一時的に保存しておくことができる、例えば一覧で表示しているときは`scr`の軽い画像を読み込ませ、選択されたとき高画質版を前面に映すなどが可能。  
`style`  
画像の描画内容などを指定できる、`class`属性を用いcssでクラスごと情報を指定する場合は不要。  
```
<img src="key-visual.png" data-full="key-visual-full.png" alt="キービジュアル" class="sample-img">
```

### \<ol>  
`<li>`タグと合わせて使うことでポッチでの箇条書きが可能。　　
`<ol>`タグの代わりに`<ul>`タグを用いることでポッチから番号による箇条書きに変更することができる。　　
```
<ol>
<li>えれが</li>
<li>さぶえれが</li>
<li>さぶさぶえれが</li>
</ol>
```
　 　↓  
1. えれが  
2. さぶえれが  
3. さぶさぶえれが
